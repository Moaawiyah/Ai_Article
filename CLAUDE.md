# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

This is an AI agents homework project (`agent_ai_HW2`). The repository is currently empty aside from a `.sixth/skills/` directory, which is used by the Claude Code harness for custom skills.

## Skills

Custom skills for this project belong in `.sixth/skills/`. Skills are Markdown files that define reusable prompts/instructions callable via `/skill-name` within Claude Code sessions.
